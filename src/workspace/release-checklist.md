# Pilot release checklist

Last updated: 18 August

## Before security review
- Confirm production data fields with Customer Success
- Finish permission test cases
- Remove test accounts from the pilot tenant

## Before pilot launch
- Northwind connector regression test complete
- Security review signed off
- Los Angeles pilot accounts created
- Monday email summary verified
- Support hand-off completed

## After week one
- Review support volume
- Measure time saved on Monday reporting
- Decide whether San Francisco joins the pilot
- Revisit mobile alert requests after pilot feedback
